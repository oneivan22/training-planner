# Актуальность темы

В последние годы популярность здорового образа жизни заметно выросла. Всё больше людей начинают заниматься спортом — кто-то в зале, кто-то дома. Однако основная проблема новичков и даже любителей — отсутствие системного подхода. Человек может неделю делать одни упражнения, потом забыть, что делал в прошлый раз, и просто бросить тренировки из-за отсутствия четкого плана.

Существует много спортивных приложений, но большинство из них перегружены функциями, требуют платной подписки или неудобны в использовании. Поэтому разработка простого, понятного и бесплатного планировщика тренировок является актуальной задачей. Такое приложение поможет пользователям структурировать свои занятия, отслеживать прогресс и не бросать спорт.

# Целевая аудитория

Приложение ориентировано на три основные группы пользователей:

Новички в спорте — люди которые только начинают заниматься и нуждаются в простом инструменте для составления программы.

Любители — те, кто уже тренируется регулярно, но хочет фиксировать результаты (веса, количество подходов) и видеть свой прогресс.

Тренеры — специалисты, которые могут выдавать программы ученикам или использовать приложение для контроля своих собственных тренировок.

# Предполагаемые функциональные возможности

1) Просмотр тренировочной программы на выбранный день недели
2) Добавление нового упражнения с указанием названия, количества подходов, повторений и рабочего веса
3) Редактирование существующего упражнения
4) Удаление упражнения из программы
5) Отметка выполненного подхода
6) Просмотр истории выполненных тренировок по датам
7) Калькулятор жима лежа по формулам (Формула Эпли, Формула Бжицки, Формула Лэндера, Формула Ломбарди, Формула Мэйхью, Формула О'Коннор, Формула Ватана. Выводит каждое значение по формулам а также среднее значение по всем формулам)
8) Чат с AI-тренером на базе нейросети — пользователь может задать вопрос о технике упражнений, получить совет по тренировкам, запросить готовый план занятий на неделю или месяц. Система обращается к API нейросети (ChatGPT или аналог) и выводит персонализированный ответ в интерфейсе чата.
9) Система ачивок (достижений) — пользователь получает значки за выполнение определённых действий
10) График прогресса по упражнениям — визуализация изменения рабочего веса в выбранном упражнении за определённый период (неделя, месяц, всё время)
11) Профиль пользователя с личной статистикой (просмотр ачивок, ФИО и тд).
