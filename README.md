## Актуальность темы

В последние годы популярность здорового образа жизни заметно выросла. Всё больше людей начинают заниматься спортом — кто-то в зале, кто-то дома. Однако основная проблема новичков и даже любителей — отсутствие системного подхода. Человек может неделю делать одни упражнения, потом забыть, что делал в прошлый раз, и просто бросить тренировки из-за отсутствия чёткого плана.

Существует много спортивных приложений, но большинство из них перегружены функциями, требуют платной подписки или неудобны в использовании. Поэтому разработка простого, понятного и бесплатного планировщика тренировок является актуальной задачей. Такое приложение поможет пользователям структурировать свои занятия, отслеживать прогресс и не бросать спорт.

## Целевая аудитория

Приложение ориентировано на три основные группы пользователей:

- Новички в спорте — люди, которые только начинают заниматься и нуждаются в простом инструменте для составления программы.
- Любители — те, кто уже тренируется регулярно, но хочет фиксировать результаты (веса, количество подходов) и видеть свой прогресс.
- Тренеры — специалисты, которые могут выдавать программы ученикам или использовать приложение для контроля своих тренировок.

## Функциональные возможности (реализовано в прототипе)

1) Просмотр тренировочной программы на каждый день недели
2) Добавление упражнения с указанием названия, количества подходов, повторений по каждому подходу и рабочего веса
3) Отметка упражнения как выполненного
4) Удаление упражнения из программы
5) Завершение тренировки дня с переносом в историю
6) Просмотр истории выполненных тренировок по датам
7) Очистка истории
8) Калькулятор жима лёжа по 7 формулам (Эпли, Бжицки, Лэндера, Ломбарди, Мэйхью, О'Коннор, Ватана) с выводом среднего значения
9) Чат с AI-тренером на базе нейросети Kimi K2 (MoonshotAI) через HuggingFace Router API — бесплатно, без ограничений

## Используемые технологии

- HTML
- CSS
- JavaScript (чистый, без фреймворков)
- HuggingFace Router API (для AI-чата)
- localStorage (хранение данных в браузере)
- PostgreSQL (планируется для дипломного проекта)

## AI-тренер

В приложении реализован чат с AI-тренером, который отвечает на вопросы о тренировках, технике упражнений и питании.

- Модель: moonshotai/Kimi-K2-Instruct-0905
- Платформа: Hugging Face (router.huggingface.co)
- Токен: получен бесплатно при регистрации на huggingface.co
- Стоимость: полностью бесплатно
